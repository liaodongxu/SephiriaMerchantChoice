# Changelog

## 1.0.0

First standalone Merchant Choice version, extracted from local Run QoL 1.3.3.

- Search, category/favorite filters and paginated item selection.
- Native transaction pricing, replenishment slot limits and eligibility checks.
- Compact left-side layout and native UI assets.
- Separate tooltip/purchase hover regions and catalog-only tooltip input passthrough.
- Independent plugin identity; rejects the legacy combined plugin to avoid duplicate patches.

Standalone version numbering starts at 1.0.0; it is not a rollback to the earlier combined UI.
